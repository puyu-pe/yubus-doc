# Venta de pasajes

Registrá un pasaje desde el detalle del viaje. Verificá el asiento y los datos
antes de confirmar: la aplicación valida la solicitud y controla la
disponibilidad del asiento.

## Pasos

1. [Ir a viajes y pasajes](#ir-a-viajes-y-pasajes)

3. [Seleccionar asiento](#seleccionar-asiento)
4. [Completar formulario](#completar-formulario)

## Completar formulario

- Ingresá el DNI del pasajero.
- Si el comprobante es una factura, ingresá el RUC. La obligatoriedad de otros
  datos puede depender de la configuración y del comprobante elegido.
- Completá los datos solicitados y revisá el asiento antes de continuar.

![formulario venta ticket](../img/sell_ticket_form.png)

## Confirmar venta

Seleccioná **Vender** para enviar el formulario. Según el estado del pasaje, el
sistema puede informar que fue registrado o reservado.

![confirmar venta](../img/sell_ticket_confirm.png)
